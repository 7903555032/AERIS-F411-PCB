# AERIS-F411 Hardware Design Specification

## Project Overview

AERIS-F411 is a professional STM32F411-based embedded development board designed for learning, rapid prototyping, and embedded firmware development using bare-metal programming.

---

# Objectives

- Professional 4-layer PCB
- USB Type-C
- STM32F411RET6
- SWD Debug Interface
- SPI Flash
- microSD Storage
- IMU Sensor
- Environmental Sensor
- CAN Interface
- RS485 Interface
- Expansion Headers
- Status LEDs
- Push Buttons
